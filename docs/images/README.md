# Docs images

Screenshots and photos for the SIMUT documentation. Every screenshot and photo in this tree is a **real capture** from running hardware or the live web interface — no mockups. The brand, the README's architecture figure and the manual's diagrams in `manual/` are drawn by code, from the tokens and the sources (the table below names the tool of the first two; `tools/manual_diagramas.py` draws the third).

## How the captures are made

- **TFT screens** — captured with:
  ```bash
  python3 tools/screen_mapper.py --out docs/images/screens --scale 2
  ```
  against a device flashed with the `pico_w_test` env. The frames are read back from the panel itself over `GET /api/screenshot`, so they show exactly what the display renders.
- **Web pages** — captured with Playwright + Chrome against the device's web interface.
